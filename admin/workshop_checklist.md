# Workshop Checklist

## Pre-Workshop (1 week before)

### Logistics
- [ ] Confirm venue and room setup
- [ ] Check projector and screen
- [ ] Verify WiFi access for participants
- [ ] Arrange power strips/extension cords
- [ ] Order refreshments (tea/coffee breaks)

### Technical
- [ ] Test all code in fresh R session
- [ ] Render all Quarto documents
- [ ] Generate synthetic datasets
- [ ] Prepare USB drives with materials (backup)
- [ ] Test RStudio Cloud workspace (optional)

### Materials
- [ ] Print handouts (3 per participant)
- [ ] Print participant roster
- [ ] Prepare name badges
- [ ] Prepare feedback forms
- [ ] Prepare certificates

### Communication
- [ ] Send reminder email to participants
- [ ] Include pre-workshop setup instructions
- [ ] Share installation guide
- [ ] Provide contact for technical issues

## Day Before

- [ ] Copy materials to presentation laptop
- [ ] Test all slides render properly
- [ ] Charge all devices
- [ ] Pack markers, whiteboard eraser
- [ ] Prepare sticky notes (red/green for help signals)

## Day 1

### Morning Setup (8:30 AM)
- [ ] Arrive 30 min early
- [ ] Test projector connection
- [ ] Open RStudio on instructor laptop
- [ ] Load sample code for demos
- [ ] Set up registration table

### During Workshop
- [ ] Distribute handouts
- [ ] Take attendance
- [ ] Monitor time for breaks
- [ ] Check on struggling participants
- [ ] Save any code modifications

### End of Day 1
- [ ] Quick feedback check
- [ ] Announce Day 2 agenda
- [ ] Address any setup issues
- [ ] Backup any participant work

## Day 2

- [ ] Review Day 1 questions
- [ ] Continue attendance
- [ ] Monitor exercise completion
- [ ] Help with individual data issues

## Day 3

- [ ] Distribute mini-project guidelines
- [ ] Support project work time
- [ ] Facilitate sharing session
- [ ] Distribute certificates
- [ ] Collect feedback forms
- [ ] Take group photo

## Post-Workshop

- [ ] Send thank you email
- [ ] Share materials link
- [ ] Compile feedback summary
- [ ] Archive participant list
- [ ] Write lessons learned notes
